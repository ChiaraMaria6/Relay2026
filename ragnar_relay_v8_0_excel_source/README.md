# Ragnar Relay Alafia Trail 2026 v8.0 Excel Data Source

This version reads dashboard data from `Relay2026_Data.xlsx`.

Upload both:
- index.html
- styles.css
- script.js
- Relay2026_Data.xlsx
- assets folder

Future data updates:
1. Edit Relay2026_Data.xlsx.
2. Upload only the updated Relay2026_Data.xlsx to GitHub.
3. GitHub Pages will show the new values at the same public URL.

Important:
- Do not rename worksheet tabs.
- Do not rename column headers.
